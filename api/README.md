# API de produção — MK Lanches

A arquitetura final deve usar uma API real entre o site público e o painel. Esta pasta é a base para essa API. O protótipo visual acima ainda não grava alterações no servidor.

Endpoints planejados: autenticação, loja por slug, categorias, produtos, adicionais, configurações e upload/storage de imagens.

Nenhuma senha real deve ser colocada no frontend.
